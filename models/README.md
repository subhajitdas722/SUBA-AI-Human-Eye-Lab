# 3D model assets

Upload the two binary GLB assets into this folder using GitHub's **Add file → Upload files** interface:

- `eye-anatomy.glb` — extracted from the Ocularium project archive (23 named anatomy meshes).
- `human_eye.glb` — downloaded DEGUIDER exterior Sketchfab GLB.

Keep these exact filenames. The viewer loads them as `./models/eye-anatomy.glb` and `./models/human_eye.glb`.
